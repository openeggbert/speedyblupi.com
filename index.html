Speedy Blupi Web Games

Experimental web versions of Speedy Blupi and Speedy Eggbert games, playable directly in the browser.

Speedy Blupi 2013

Windows Phone version · Fully functional

A fully functional web port of the Windows Phone version of Speedy Blupi 2013. The game is playable, including sound. Save-state persistence is implemented, so the game remembers its state after reloading the page.

Play Speedy Blupi 2013 - modern C++ version with persistence

Play Speedy Blupi 2013 - obsolete C# version without persistence

Speedy Eggbert 2

Decompiled Windows version · Partially functional

A decompiled web version of Speedy Eggbert 2. It is currently only partially functional. Save-state persistence is not implemented yet, sound works, music does not work in the web version for now.

Play Speedy Eggbert 2
Note:
  • These browser versions are experimental ports.
  • Some features may still be missing or incomplete depending on the game.
  • The known issues and missing features are actively being worked on.
